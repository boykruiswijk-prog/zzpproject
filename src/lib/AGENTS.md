# Afspraken src/lib
- Teamrollen hebben geen SELECT op IBAN-kolommen: nooit select("*") op leads/ondernemingen/screening_aanvragen e.d. (kolomlijsten in src/lib/veiligeKolommen.ts), masker/geldigheid via RPC iban_maskers, mandaten via klant_mandaat_overzicht, volledig IBAN alleen via iban_inzien (IbanInzien, gelogd). Nieuwe kolom op die tabellen krijgt een expliciete kolom-GRANT. Waarom: inzage herleidbaar, geen ruwe bankgegevens in de browser.
- Leadvlag (later/actie) alleen via RPC zet_lead_vlag/verwijder_lead_vlag (trigger guard_lead_vlag); "geparkeerd" = SQL lead_vlag_geparkeerd, byte-gelijk aan isGeparkeerd in src/lib/leadVlag.ts. Waarom: tabs, tellers en dagoverzicht hanteren één regel.
- Contractkorting: bedrag_per_periode blijft bruto; korting alleen via RPC zet_contract_korting/verwijder_contract_korting (guard_contract_korting), netto via SQL korting_netto/korting_voor_periode in facturatie_kandidaten, gespiegeld in src/lib/contractKorting.ts; Exact-regel UnitPrice netto zonder Discount-veld. Waarom: nooit terugwerkend, creditnota's rekenen met het betaalde bedrag.
- Klantvlag (ondernemingen) alleen via RPC zet_klant_vlag/verwijder_klant_vlag (trigger guard_klant_vlag, log klant_vlag_log); zelfde geparkeerd-regel als leadVlag (filterOpTab/isGeparkeerd). Waarom: leads en klanten hanteren één vlagregel.
